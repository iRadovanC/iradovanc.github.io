# Signál 44

Jednoduchá 2D hra o polním spojaři, napsaná v čistém HTML, CSS a JavaScriptu bez knihoven a dalších závislostí.

## Spuštění

Otevřete soubor `index.html` v libovolném moderním prohlížeči. Není potřeba instalace ani lokální server.

## Ovládání

- `WASD` nebo šipky — pohyb
- `E` — oprava vysílačky / předání rozkazu
- `Mezerník` — úhybný kotrmelec
- `P` — pauza
- `M` — zvuk

Na dotykovém zařízení se ovládací prvky zobrazí přímo ve hře.
