# Nulový bod

Jednoduchá 2D střílečka z pohledu první osoby. Hra nemá žádné externí závislosti.

## Spuštění

Otevřete soubor `index.html` v moderním prohlížeči. Není potřeba instalace ani lokální server.

## Ovládání

- Myš nebo dotyk: míření a střelba
- Šipky nebo WASD: míření
- Mezerník nebo Enter: výstřel
- R: přebití

Rekord se ukládá do `localStorage` v prohlížeči.
